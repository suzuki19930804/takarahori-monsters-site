サポート

「宝ほりモンスターズ」についてのご質問・不具合のご報告は、GitHub の Issues からお寄せください（GitHub のアカウントが必要です）。いただいた内容は公開されるので、個人情報は書かないでください。

よくある質問

データを新しい端末に移したい
古い端末の「せってい」で「データをコピー」を押し、コピーした文字を新しい端末に送ります（メモアプリやメールなど）。新しい端末でその文字をコピーしてから、「せってい」の「データをはりつけ」を押してください。
クイズを出さないようにしたい・むずかしさを変えたい
「せってい」の「クイズを だす」で、クイズを出さないようにできます。出すジャンルもえらべます。こども向け・おとな向けのクイズは、「ハンデ」でプレイヤーごとにえらべます。
年の差があって勝負にならない
「せってい」の「ハンデ」で、勝つのに必要な宝石の数、はてなボックスから出るアイテム、必殺技のゲージのたまりかたを、プレイヤーごとに変えられます。
広告はどのくらい出ますか
何試合かに 1 回、試合が終わったあとに出ます。試合の途中には出ません。

English

For questions or bug reports about the app, please open an issue on GitHub Issues (a GitHub account is required). Issues are public, so please don't include personal information.

How do I move my data to a new device?
On the old device, open Settings (せってい) and tap Copy Data (データをコピー), then send the copied text to the new device. On the new device, copy that text and tap Paste Data (データをはりつけ) in Settings.
How often are ads shown?
Once every few matches, after a match ends. Ads are never shown during a match.
